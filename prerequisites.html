01. Onboarding Checklist

01. Liste de Contrôle Préalable

Cloud Infrastructure

1. Oracle Cloud Account (Verification Card)

An international Visa or Mastercard issued by a physical bank (e.g., AGB / Gulf Bank Algeria, BDL, BEA, Société Générale) is required to complete account verification.

Important Note:

Oracle Cloud strictly requires a physical bank card. Virtual prepaid cards (such as RedotPay or Pyypl) are automatically rejected by Oracle's fraud system.

1. Compte Oracle Cloud (Carte de Vérification)

Une carte Visa ou Mastercard internationale émise par une banque physique (ex. AGB, BDL, BEA, Société Générale) est requise pour valider le compte.

Note Importante :

Oracle Cloud exige strictement une carte bancaire physique. Les cartes prépayées virtuelles (type RedotPay ou Pyypl) sont rejetées par le système anti-fraude d'Oracle.

POS Synchronization

2. XL POS E-Commerce Module Activation

  • Contact Boitex Info (official XL POS distributor in Algeria) to activate the Connecteur E-Commerce Standard (WebServices API) license on your store system.
  • Obtain and provide the resulting API Key and WebService Endpoint URL.

2. Activation du Module E-Commerce XL POS

  • Contacter Boitex Info (distributeur officiel XL POS en Algérie) pour activer la licence Connecteur E-Commerce Standard (API WebServices).
  • Obtenir et transmettre la Clé API et l'URL Endpoint WebService générées.
Web Address

3. Domain Name Registration

  • Ownership access to your chosen web address (e.g., profootplus.dz or profootplus.com).
  • Note: Technical DNS configuration and SSL security setup will be handled on your behalf.

3. Réservation du Nom de Domaine

  • Accès à la propriété de votre adresse web (ex. profootplus.dz ou profootplus.com).
  • Note : La configuration technique des DNS et la sécurité SSL seront prises en charge par nos soins.
