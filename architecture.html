02. XL POS Integration Setup & Workflow

02. Intégration XL POS & Flux de Synchronisation

Activation Guide

3-Step POS Setup

  1. Request Module: Ask Boitex Info (Bir Khadem, Alger) to enable the Connecteur E-Commerce Standard (WebServices API) license on your XL POS register.
  2. Obtain Credentials: Receive your secure API Key and Endpoint URL from Boitex Info.
  3. Handover: Send both credentials to us to activate automated backend security and sync listeners.

Activation en 3 Étapes

  1. Activer le Module : Demander à Boitex Info (Bir Khadem, Alger) d'activer la licence Connecteur E-Commerce Standard (API WebServices) sur votre caisse XL POS.
  2. Obtenir les Accès : Récupérer votre Clé API et votre URL Endpoint sécurisée fournies par Boitex Info.
  3. Transmission : Nous transmettre ces deux identifiants pour connecter le moteur de synchronisation.
Two-Way Flow

Real-Time Data Logic

  • In-Store Purchase → Website: Barcode scanned at shop register → XL POS sends API payload → Website stock decreases within milliseconds.
  • Online Purchase → In-Store POS: Customer orders on website → Order drops into XL POS register as an incoming command ticket → Counter stock auto-deducts.

Flux de Données en Direct

  • Vente Magasin → Site Web : Code-barres scanné en caisse → Payload API instantané XL POS → Le stock du site diminue en quelques millisecondes.
  • Commande Web → Caisse Magasin : Commande passée en ligne → Transfert direct sur la caisse XL POS sous forme de ticket → Déduction automatique du stock physique.
